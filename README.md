# Space Grade Linux Technical Steering Committee

This repository holds the governance of Space Grade Linux (SGL): its Technical Charter, and the Request for Comment (RFC) process the Technical Steering Committee (TSC) uses to decide changes that are bigger than one pull request.

- [CHARTER.md](CHARTER.md): the Space Grade Linux Technical Charter.
- [rfcs/](rfcs/): how RFCs work, the RFC template, and the RFCs themselves.
- [meeting-minutes/](meeting-minutes/): minutes of the monthly public project meeting and of TSC meetings.

## Technical Steering Committee

The TSC is responsible for all technical oversight of the project (charter section 2.a). Its voting members are the project's committers (section 2.b), currently listed in [meta-sgl MAINTAINERS.md](https://github.com/elisa-tech/meta-sgl/blob/main/MAINTAINERS.md). TSC meetings are intended to be open to the public (section 2.b).

The code lives in [meta-sgl](https://github.com/elisa-tech/meta-sgl). Project discussion happens on the [mailing list](https://lists.elisa.tech/g/space-grade-linux/).

## Contributing

Changes to this repository are proposed as pull requests. Commits carry a Developer Certificate of Origin sign-off (`git commit -s`). The [LF Projects Code of Conduct](https://lfprojects.org/policies/) applies to everyone in the project (charter section 4.b).
